# Ordner für den Browser-Chat (Claude mit Browser-Steuerung)

Hier hält der Browser-Chat fest, was er im Browser erledigt hat. Claude Code liest diesen Ordner zu Beginn jeder
Sitzung und ist so immer auf dem neuesten Stand.

**Achtung: Das Repo ist öffentlich.** Niemals Passwörter, Zugangscodes, Wiederherstellungscodes, Zahlungs-, Bank-
oder Steuerdaten, Ausweisdaten oder Screenshots mit privaten Daten hier ablegen. Erlaubt: Kontonamen (@…), Links,
Status, offene Schritte, Fragen an Claude Code.

## So trägt der Browser-Chat etwas ein
1. Datei öffnen: https://github.com/Twista-hub/jarvis/edit/main/docs/browser/protokoll.md
2. Oben unter „Einträge“ einen neuen Eintrag ergänzen (Datum, was erledigt, was offen, Fragen).
3. Rechts oben auf **„Commit changes…“** und im Fenster nochmals auf **„Commit changes“** klicken.

Neue Datei anlegen (z. B. für ein neues Thema): https://github.com/Twista-hub/jarvis/new/main/docs/browser
→ Dateiname eintragen (z. B. `social-media.md`) → Text → **„Commit changes…“**.

## Aufträge von Claude Code
Liegen in `docs/auftraege/` (z. B. `crewtender-konten.md`).
